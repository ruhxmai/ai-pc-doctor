# Неделя 12. Простая нейронная сеть

## Задание
Создать и обучить простую нейронную сеть. Выполнить распознавание и оценить точность.

## Сеть — `pcdoctor/neural.py`
Многослойный перцептрон, написанный **с нуля на numpy** (без фреймворков машинного обучения):

```
вход: 20 признаков (0/1) → Dense 32, ReLU → Dense 16, ReLU → Dense 8, softmax → P(неисправность)
параметров: 1336
```

| Элемент | Реализация |
|---|---|
| Инициализация весов | Хе (He): N(0, √(2/n_in)) — для ReLU |
| Функция потерь | перекрёстная энтропия + L2-регуляризация (λ = 0.001) |
| Обратное распространение | ручной вывод: ∂L/∂z = softmax − one_hot, производная ReLU = [z > 0] |
| Оптимизатор | Adam (β₁ = 0.9, β₂ = 0.999), мини-батчи по 32, lr = 0.003 |
| Ранняя остановка | по точности на валидации (patience = 20), восстанавливаются лучшие веса |
| Проверка корректности | тест сравнивает аналитические градиенты с численными (конечные разности) |

Данные — датасет недели 11: обучение 1202 / валидация 298 / тест 500.

## Обучение
```
эпоха   1  loss=1.6360  train_acc=0.514  val_acc=0.483
эпоха  10  loss=0.3663  train_acc=0.895  val_acc=0.859
эпоха  20  loss=0.3174  train_acc=0.911  val_acc=0.862
ранняя остановка на эпохе 29; лучшая эпоха — 9
```
Подбор шага обучения: lr = 0.003 → 0.858, lr = 0.001 → 0.852, lr = 0.0005 → 0.848.

## Точность (тестовая выборка)
| Модель | Accuracy | Top-3 |
|---|---|---|
| Нейросеть (MLP) | **0.858** | 0.972 |
| Наивный Байес (неделя 11) | 0.870 | 0.976 |

Нейросеть немного уступает наивному Байесу, и это ожидаемо: датасет сгенерирован из модели
с условно независимыми признаками — ровно из того предположения, на котором построен наивный Байес.
На реальных данных с зависимыми признаками преимущество было бы у нейросети.
Обе модели используются в экспертной системе (неделя 13) как ансамбль.

## Распознавание новых случаев
```
Компьютер не включается + Вентиляторы не вращаются
   → Неисправность блока питания (98%)
Артефакты на экране + Вылеты в играх + Шум вентиляторов
   → Неисправность видеокарты (99%)
ОС не загружается + Проблема после обновления
   → Повреждение операционной системы (87%);  Проблема с драйверами (7%)
```
