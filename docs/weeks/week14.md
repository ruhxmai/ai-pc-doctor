# Неделя 14. ИИ-помощник

## Задание
Создать ИИ-помощника. Реализовать ввод запроса, анализ, поиск решения и формирование ответа.

## Конвейер обработки запроса — `pcdoctor/assistant.py`
```
 ввод текста ─► анализ ─────────────────────────────► поиск решения ─────────► ответ
               • нормализация, токенизация             • экспертная система     • шаблоны ответов
               • разбиение на клаузы по , . и «и/а/но»  • фреймы                 • учёт контекста
               • признаки по шаблонам основ слов        • семантическая сеть     • уточняющие вопросы
               • отрицания: «не шумит», «гари нет»      • Байес (выбор вопроса)
               • намерение (intent), сущности, числа
```

### Анализ
* **Признаки** распознаются по шаблонам основ из базы знаний: шаблон `"вентил не крут"` срабатывает,
  если в одной клаузе есть слова, начинающиеся с «вентил», «крут», и слово «не».
  Отрицания и основы из 1–2 букв сравниваются точно, чтобы «ос» не совпадало с «особенно».
* **Отрицание признака**: «синего экрана **нет**», «**не** шумит», «**без** запаха гари» → признак
  помечается как отсутствующий. Отрицание действует только внутри своей клаузы.
* **Намерения** (12): диагностика, опрос, объяснение, «что такое», «почему / причины», «как исправить»,
  «мой компьютер», температура, сброс, помощь, приветствие, выход.
* **Сущности** — компоненты, неисправности, признаки: «жёсткий диск» → `hdd`, «вирус» → `malware`.

### Поиск решения
| Намерение | Источник знаний |
|---|---|
| диагностика / опрос / объяснение | экспертная система (логика + продукции + Байес + нейросеть) |
| «почему появляется X» | семантическая сеть: `query(?, manifests, X)` + вероятности Байеса |
| «что такое X» | фреймы (назначение, иерархия, срок службы) + сеть (неисправности, экземпляры) |
| «как исправить X» | фрейм неисправности (шаги устранения, нужен ли сервис) |
| «мой компьютер», «температура процессора 97» | фреймы экземпляров, демоны `if_needed` / `if_added` |

### Формирование ответа и диалог
* Помощник **помнит контекст**: признаки накапливаются («ещё пищит»), «сброс» начинает заново.
* При уверенности ниже 85 % помощник **сам задаёт уточняющий вопрос** (максимальный прирост информации),
  на «почему» объясняет, зачем спрашивает.
* «объясни» — дерево логического доказательства и цепочка продукций.
* `/debug` показывает результат анализа запроса.

## Пример диалога
```
Вы: Компьютер иногда сам перезагружается, синего экрана нет
PC Doctor: Распознал признаки: самопроизвольные перезагрузки. Учту, что нет: синий экран (BSOD).
           Пока больше всего похоже на «Перегрев процессора» (43%), но нужно уточнить.
           Вопрос 1: Температура процессора выше 85 °C или корпус сильно горячий?
Вы: да
PC Doctor:  95.5%  Перегрев процессора   Байес 90% | нейросеть 97% | правила: логика, продукции
           Как устранить — чистка системы охлаждения и замена термопасты: ...
Вы: почему появляется синий экран?
PC Doctor: «Синий экран (BSOD)» может быть вызван:
             • Неисправность оперативной памяти — 32%
             • Проблема с драйверами — 22% ...
Вы: температура процессора 104
PC Doctor: ВНИМАНИЕ: Intel Core i5-12400F: 104 °C > допустимых 100 °C — перегрев!
```

## Качество распознавания
Тест `tests/test_assistant.py` проверяет 14 фраз на естественном языке (признаки и отрицания)
и 13 намерений — всё распознаётся верно.

```bash
python demos/week14_assistant.py       # демонстрационный диалог
```
