# Неделя 13. Экспертная система

## Задание
Создать экспертную систему. Объединить базу знаний, правила и механизм вывода.

## Архитектура — `pcdoctor/expert_system.py`
```
                     ┌──────────────── База знаний (knowledge.json) ────────────────┐
                     │ компоненты · признаки · неисправности · P(признак|неиспр.)   │
                     └──────┬──────────────┬──────────────┬──────────────┬──────────┘
                            ▼              ▼              ▼              ▼
  признаки ──► Логический вывод   Продукции       Байес + нейросеть   Фреймы + сем. сеть
               (обратный, AND/    (прямой вывод,  (вероятности        (комплектующие
               OR/NOT, «как?»)    советы, флаги)  гипотез)            пользователя, дифф. диагноз)
                            └──────────────┴───────┬──────┴──────────────┘
                                                   ▼
                     уверенность = 0.35·Байес + 0.35·нейросеть + 0.30·правила
                                                   ▼
                  диагноз · шаги устранения · советы · предупреждения · объяснение
```

| Компонент | Роль в экспертной системе |
|---|---|
| Логический вывод (нед. 5–6) | доказывает `diagnosis(F)`, даёт дерево доказательства для объяснения |
| Продукционная система (нед. 7) | прямой вывод: диагноз, флаги опасности, советы (отключить от сети, сделать копию, сервис) |
| Наивный Байес (нед. 11) | апостериорные вероятности **с учётом отсутствующих признаков**; выбор вопросов |
| Нейросеть (нед. 12) | независимая оценка вероятностей (ансамбль) |
| Фреймы (нед. 8–9) | конкретные комплектующие пользователя, их возраст и остаток ресурса → предупреждения |
| Семантическая сеть (нед. 10) | дифференциальная диагностика: какие признаки отличают две главные гипотезы |

## Консультация (диалог)
Система сама задаёт вопросы. Следующим выбирается признак с **максимальным ожидаемым приростом
информации**:

IG(s) = H(P(F)) − [P(s)·H(P(F | s)) + P(¬s)·H(P(F | ¬s))]

Остановка — когда уверенность ≥ 90 %, вопросы перестали быть информативными или задано 10 вопросов.
На ответ **«почему»** система объясняет, зачем задан вопрос (между какими гипотезами он выбирает).

```
? Температура процессора выше 85 °C или корпус сильно горячий? почему
Сейчас наиболее вероятны:
  Перегрев процессора — 33%; признак встречается с вероятностью 90%
  Неисправность оперативной памяти — 27%; признак встречается с вероятностью 5%
  Неисправность блока питания — 24%; признак встречается с вероятностью 5%
? Температура процессора выше 85 °C ...? да
? Вентиляторы сильно шумят или гудят? да
   99.2%  Перегрев процессора   Байес 99% | нейросеть 99% | правила: логика, продукции
```
