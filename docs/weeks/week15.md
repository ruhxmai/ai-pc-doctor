## Объединение — [`main.py`](../../main.py)
Единая точка входа ко всем модулям:

```
================================================================
  PC Doctor 1.0.0 — ИИ-помощник для диагностики неисправностей ПК
================================================================
  1. Чат с ИИ-помощником
  2. Консультация экспертной системы (система задаёт вопросы)
  3. Логический вывод: запросы к базе знаний
  4. Продукционная система: прямой вывод
  5. Фреймы: просмотр, поиск, изменение свойств
  6. Семантическая сеть: поиск связанных объектов
  7. Машинное обучение: переобучить и оценить модели
  8. Сведения о базе знаний
  0. Выход
```

Режимы командной строки: `chat`, `ask "текст"`, `consult`, `train`, `test`.

Все модули используют одну базу знаний и общий объект `ExpertSystem`, поэтому изменения видны везде:
например, температура, записанная в чате, меняет статус фрейма процессора.
