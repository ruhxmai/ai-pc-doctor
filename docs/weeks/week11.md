# Неделя 11. Датасет и модель классификации

## Задание
Создать датасет. Обучить модель классификации. Получить и оценить результаты.

## Датасет — [`data/dataset.csv`](../../data/dataset.csv), код `pcdoctor/dataset.py`
2000 «обращений пользователей»: 20 бинарных признаков (наблюдается / нет) и метка неисправности.
Генерация по базе знаний:
1. неисправность выбирается с априорной вероятностью `prior`;
2. каждый признак появляется с вероятностью P(признак | неисправность) из `knowledge.json`
   (для «чужих» признаков — фоновая вероятность 0.05, это шум);
3. в примере не меньше 2 признаков (пользователь всегда что-то описывает).

В среднем 3.9 признака на пример. Классы сбалансированы (209–283 примера).
Разбиение — стратифицированное, 75 % / 25 % (1500 / 500).

## Модели — `pcdoctor/classifier.py`
| Модель | Идея |
|---|---|
| **Наивный Байес** (основная) | P(F \| s) ∝ P(F)·Π P(sᵢ\|F)^xᵢ (1−P(sᵢ\|F))^(1−xᵢ), параметры по частотам со сглаживанием Лапласа; реализован с нуля на numpy |
| Байес эксперта | та же формула с вероятностями из базы знаний, без обучения |
| kNN (k=7) | голосование 7 ближайших примеров по расстоянию Хэмминга |

Байесовская модель умеет работать с **частично известными признаками** (`posterior`):
неизвестные признаки просто не входят в произведение. Эта возможность используется
в экспертной системе, чтобы выбирать, какой вопрос задать следующим.

## Результаты (тестовая выборка, 500 примеров)
| Метрика | Значение |
|---|---|
| Accuracy | **0.870** |
| Macro F1 | 0.865 |
| Top-3 accuracy | 0.976 |

Лучше всего распознаются неисправности блока питания (F1 0.95), хуже всего — повреждение ОС (F1 0.69):
её чаще всего путают с отказом накопителя (11 ошибок), потому что у них общие признаки
(«не загружается», «повреждены файлы», «зависания»).

5-кратная перекрёстная проверка:
```
Наивный Байес (обучен на данных)   accuracy = 0.877 ± 0.013
Байес на вероятностях эксперта     accuracy = 0.884 ± 0.014
k ближайших соседей, k=7           accuracy = 0.858 ± 0.007
```
Обученная модель практически совпадает с экспертной: выученные P(признак | неисправность)
близки к экспертным (0.84 и 0.85 для «не включается» при неисправном БП), то есть по данным
восстанавливаются знания эксперта.
