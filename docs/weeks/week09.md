# Неделя 9. Программа работы с фреймами

## Задание
Реализовать программу работы с фреймами. Добавить поиск и изменение свойств объектов.

## Операции над фреймами — `pcdoctor/frames.py` (класс `FrameSystem`)
| Метод | Назначение |
|---|---|
| `find(условия, класс)` | поиск экземпляров по значениям слотов **с учётом наследования и демонов** |
| `instances_of(класс)` | все экземпляры класса и его подклассов |
| `get / origin` | значение слота и фрейм, от которого оно унаследовано |
| `set(фрейм, слот, значение)` | изменение свойства; вызывает демон `if_added` |
| `delete_slot` | удаление собственного значения — снова действует унаследованное |
| `create / delete` | создание экземпляра / удаление фрейма (запрещено, если есть наследники) |
| `save / load` | сохранение и загрузка в JSON (демоны сохраняются по имени) |

Условия поиска: `слот=значение`, `!=`, `>`, `<`, `>=`, `<=`, `~` (подстрока или элемент списка),
просто `слот` — «слот задан». Значения `да/нет` и числа распознаются автоматически.

## Интерактивная программа — `pcdoctor/frames_cli.py`
```
фреймы> find класс:heat_source max_temp>=95
Найдено: 1
  cpu_i5_12400             Intel Core i5-12400F

фреймы> find lifetime_left<0                ← слот вычисляется демоном if_needed
  hdd_seagate_1tb          Seagate BarraCuda 1 ТБ

фреймы> set gpu_rtx_3060 current_temp 97
gpu_rtx_3060.current_temp: None → 97
  демон: ВНИМАНИЕ: NVIDIA GeForce RTX 3060: 97 °C > допустимых 93 °C — перегрев!

фреймы> del ssd_samsung_970 typical_lifetime_years
Удалено. Теперь typical_lifetime_years = 8 (от ssd)
```
